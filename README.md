# OpenCCGovForRime

为 Rime 输入方案提供大陆规范繁体输出，保留简体／繁体切换。

项目正在开发，暂未提供可安装版本。

## 支持范围

计划支持雾凇拼音及其全部双拼、朙月拼音、仓颉五代和五笔86，面向鼠须管（macOS）、小狼毫（Windows）和中州韵（Linux）。

## 使用方式

本项目只提供派生方案和 OpenCC 转换文件，需要先安装对应的原输入方案。安装与使用教程将在可安装版本发布后补充。

## 转换来源

采用 [TerryTian-tech 的 t2gov 转换方案](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards)。该方案并非政府官方 OpenCC 项目，部分映射经过调整，不代表与《通用规范汉字表》完全一致。
